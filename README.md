# ProxmoxAsCode

## Purpose

Provisions and manages Proxmox VE infrastructure and virtual machines.

## Example contents

Platform entry scripts, reusable platform functions, template preparation, and configuration examples.

## Scope

Guest OS, role, and application recipes belong in InfraAsCode. Customer and lab deployments define topology and compose the repositories.

## Dependencies

PVE API connectivity and permissions for nodes, storage, networking, and templates.
